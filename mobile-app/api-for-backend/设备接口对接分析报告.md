## 二、接口能力分析

### 2.1 已满足的设备功能

| 功能 | 四象API | 说明 |
|------|---------|------|
| 获取用户设备列表 | `POST /devices/endUsers/{userId}/rentPage` | 可获取用户租用设备分页列表 |
| 获取设备详情 | `GET /devices/{id}` | 可获取单个设备完整信息 |
| 设备在线状态 | `status` 字段 | ONLINE / OFFLINE 两种状态 |
| 设备信号强度 | `percentage` 字段 | 电量百分比/信号强度 |
| 租用时间信息 | `rentStartDate`, `rentEndDate` | 租用起止时间 |
| 设备解绑 | `DELETE /devices/{id}/unbindRentUser` | 解绑承租用户 |
| 设备事件日志 | `POST /devices/{id}/events/page` | 设备上下线等事件 |
| 设备算力消耗 | `POST /devices/{id}/tc/page` | 账户流量消耗记录 |

### 2.2 部分满足（需扩展/澄清）

| 功能 | 四象API现状 | 问题 |
|------|-------------|------|
| 设备业务状态 | `status` 字段仅有 ONLINE/OFFLINE | 缺少 busy（运行中）、error（异常）等业务状态 |
| 当前AI模型 | `model` 字段为产品型号 | 返回的是硬件产品型号，不是AI模型名称（如FinBERT） |
| 设备doAction | `POST /devices/{id}/doAction/{action}` 存在 | action 参数类型未知，需向四象确认 |

## 六、字段映射参考

### 6.1 四象设备字段 → 前端字段

| 四象字段 | 类型 | 前端对应 | 说明 |
|----------|------|----------|------|
| `id` | integer | `deviceId` | 设备主键ID |
| `name` | string | `name` | 设备名称 ✅ |
| `sn` | string | `deviceId` | 设备序列号 |
| `uuid` | string | `uuid` | 设备UUID |
| `status` | string | `isOnline` | ONLINE→true, OFFLINE→false |
| `percentage` | number | `networkStatus` | 信号/电量百分比 ✅ |
| `model` | string | `currentModel` | ⚠️ 需确认是产品型号还是AI模型 |
| `rentStartDate` | string | `bindTime` | 租用开始时间 ✅ |
| `rentEndDate` | string | `rentEndDate` | 租用到期时间 ✅ |
| `onlineTime` | integer | `lastSeen` | 最近在线时间（时间戳）✅ |
| `firmwareVersion` | string | `firmwareVersion` | 固件版本 |
| `hardwareVersion` | string | `hardwareVersion` | 硬件版本 |
| `address` | string | `address` | 设备地址 |

### 6.2 状态枚举值

| 四象枚举值 | 前端显示 |
|------------|----------|

| `OFFLINE` | 离线 |
