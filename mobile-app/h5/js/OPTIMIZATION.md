## 三、新发现的问题

### 3.1 路径不统一问题

| 页面 | JS 路径风格 |
|------|------------|
| device.html | `/h5/js/...` |
| home.html | `/h5/js/...` |
| whale-chat.html | `/h5/js/...` |
| index.html | `/h5/js/...` |
| device-chat.html | `js/...` |
| skill-execute.html | `js/...` |

### 3.2 建议统一方案

统一使用相对路径 `js/`，原因：
- 移动位置后路径不受影响
- Vite 迁移更方便
