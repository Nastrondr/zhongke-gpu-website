## 三、接口配置

### 3.1 已配置的API接口

#### 订单相关接口 (endpoints.js)

```javascript
order: {
  listByUser: { method: 'POST', path: '/manage/api/v1/orders/users/:userId/page' },
  create: { method: 'POST', path: '/manage/api/v1/orders/creation' },
  detail: { method: 'GET', path: '/manage/api/v1/orders/:id' },
  cancel: { method: 'PUT', path: '/manage/api/v1/orders/:id/cancel' },
  pay: { method: 'POST', path: '/manage/api/v1/orders/:id/pay' }
}
```

#### API模块方法 (index.js)

```javascript
Api.Order = {
  listByUser(userId, requestBody),
  create(orderData),
  getDetail(orderId),
  cancel(orderId),
  pay(orderId, { orderId, payChannel })
}
```

### 3.2 已实现的对接

| 接口 | 调用位置 | 对接状态 | 说明 |
|------|---------|----------|------|
| `Api.Order.listByUser` | `loadOrders()` | 仅获取订单数量 | 未解析完整数据 |
| `Api.Order.cancel` | `cancelOrder()` | 已对接 | 支持取消订单 |
| `Api.Order.pay` | `payOrder()` | 未对接 | 仅弹窗提示 |

### 3.3 缺失的接口

| 接口 | 必要性 | 说明 |
|------|---------|------|
| **获取订单列表（完整数据）** | 高 | 当前仅获取数量，需解析完整订单数据渲染 |
| **创建订单** | 中 | 无入口调用 |
| **订单支付** | 高 | 需跳转支付页面或唤起支付SDK |
| **订单详情查询** | 中 | 可在订单卡片点击时调用 |

## 四、从下单到支付的流程闭环分析

### 4.1 当前流程状态

```
用户视角:
┌─────────────────────────────────────────────────────────────┐
│  1. 下单                                                    │
│     ❌ 未实现 - 无商品详情页和下单入口                          │
├─────────────────────────────────────────────────────────────┤
│  2. 支付                                                    │
│     ⚠️ 部分实现 - 仅有弹窗提示，未对接真实支付                   │
├─────────────────────────────────────────────────────────────┤
│  3. 订单记录                                                │
│     ✅ 已实现 - 显示假数据，支持筛选/排序                          │
├─────────────────────────────────────────────────────────────┤
│  4. 查看详情                                                │
│     ⚠️ 部分实现 - 仅显示订单号，未对接详情API                   │
├─────────────────────────────────────────────────────────────┤
│  5. 取消订单                                                │
│     ⚠️ 部分实现 - 已对接API但需确认功能完整性                   │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 流程闭环所需接口

| 步骤 | 接口 | 状态 | 需要后端配合 |
|------|------|------|-------------|
| 下单 | `POST /orders/creation` | 已配置 | 需要商品系统提供商品信息 |
| 支付 | `POST /orders/:id/pay` | 已配置 | 需要支付渠道（微信/支付宝）配合 |
| 查看 | `GET /orders/:id` | 已配置 | ✅ 就绪 |
| 列表 | `POST /orders/users/:userId/page` | 已配置 | ✅ 就绪 |
| 取消 | `PUT /orders/:id/cancel` | 已配置 | ✅ 就绪 |

### 4.3 结论

**当前无法完成从下单到支付的流程闭环**，原因：

1. **无商品入口** - 缺少商品详情页和下单入口
2. **支付未对接** - 仅有弹窗提示，未对接真实支付渠道
3. **订单数据未渲染** - 仅显示假数据，未对接真实订单数据
