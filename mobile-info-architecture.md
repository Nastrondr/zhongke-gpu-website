## 七、数据流向

### 7.1 用户登录流程

```
1. 用户访问 mobile-login.html
2. 填写表单 → 提交到后端 /api/auth/login
3. 后端验证 → 返回 JWT token + 用户信息
4. 前端保存 token 到 localStorage
5. 跳转回 mobile-app.html
6. 首页读取 token 显示用户信息
```

### 7.2 设备绑定流程

```
1. 用户进入 mobile-account-binding.html
2. 输入设备绑定码
3. 提交绑定请求
4. 后端验证并绑定设备
5. 返回绑定结果
6. 页面更新绑定状态
```

### 7.3 词元生产流程

```
1. 用户进入 mobile-token-production.html
2. 查看当前词元数量
3. 点击"开始生产"按钮
4. 后端记录生产任务
5. 定时更新词元数量
6. 用户可查看生产记录
```

## 九、技术实现要点

### 9.1 前端技术
- 原生 HTML + CSS + JavaScript
- 响应式布局（移动端优先）
- localStorage 存储用户状态
- Fetch API 调用后端接口

### 9.2 后端接口（待完善）
- `/api/auth/register` - 注册
- `/api/auth/login` - 登录
- `/api/auth/me` - 获取用户信息

### 9.3 页面通信
- URL 参数传递（如 `?tab=profile`）
- localStorage 共享登录态
- 页面跳转携带状态
